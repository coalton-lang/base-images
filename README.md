# Base Images

This repository contains base images for the
[Coalton-Compat](https://github.com/c-kloukinas/coalton-compat)
CI pipeline.
Coalton-Compat is a fork of [Coalton](https://github.com/coalton-lang/coalton/),
just like these images are a fork of [Coalton
base-images](https://github.com/coalton-lang/base-images).

The following implementations are supported:
- [SBCL](./sbcl)
- [Clozure CL](./ccl)

The following implementations have been disabled due to license expiration:

- [Allegro CL](./allegro)

There are also some images for testing when porting:
- [ABCL](./abcl)
- [ECL](./ecl)
- [CLASP](./clasp)
